# LocalReel 0.5.4

The release that gives LocalReel a face in the notification area: the product
icon instead of a generic play triangle, a menu in the system language, and a
first-run hint for Windows 11's hidden-icons corner.

## Changes

### The tray icon is the product icon

- The executable and the tray icon now carry the LocalReel mark (dark tile,
  peach ring, play button) at every size Explorer asks for, instead of the old
  black-triangle placeholder. Shortcuts, the taskbar and the notification-area
  icon all match the web app.
- The tooltip names the version and the state: `LocalReel 0.5.4 - running`
  (`- 运行中` on a Chinese system).

### The menu speaks the system language

- `打开 LocalReel` / `退出` on a Chinese Windows, `Open LocalReel` / `Quit`
  otherwise, detected from `GetUserDefaultUILanguage`; the tray was the last
  English-only surface in a bilingual application.
- Left click still opens the browser, right click opens the menu.

### First run points at the hidden icons

- Windows 11 puts a new notification-area icon under the hidden-icons chevron
  and offers no supported way for an application to pin itself. The first run
  per library now shows one balloon: LocalReel is running in the background,
  the icon is in the hidden icons, and it can be dragged onto the taskbar to
  keep it visible.
- The hint is remembered in the data directory, so it appears once rather than
  on every start.

## Upgrading

- Install over the previous version. Existing libraries are untouched: a
  relative `[data] dir` still resolves against the install folder (0.5.3 rule).

## Verification

- `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
  `cargo test --workspace` - 280 tests.
- Live check: a desktop-mode start logs `tray icon installed` and the icon
  resource is the mark (verified by extracting the icon from the built
  executable at 16, 32 and 256 px).
