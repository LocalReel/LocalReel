# LocalReel 0.4.1

## Changes

- The language switch is a single small globe button that shows the current
  language and toggles on click; the reels back button is smaller.
- Landscape video shows a **Full screen** button below the picture. It
  fullscreens the player and requests landscape orientation where the platform
  supports it; iOS uses the native video player.
- Temporary speed is bound to the right third of the video: long-press for 2×,
  release to restore 1×. The left side no longer triggers it.

## Verification

- Rust workspace: 87 tests, `clippy -D warnings`, `fmt`.
- Web: 25 unit tests, strict TypeScript build.
- Installer: silent install to the default and to a custom directory, `--version`,
  `doctor`, uninstall.
- Browser checks: fullscreen entry, 2× on the right side, 1× after release, no
  2× on the left side.
