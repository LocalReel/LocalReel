# LocalReel 0.5.2

Same feature set as 0.5.1 - supervised plugins and a per-user Windows setup -
with the Windows setup actually attached to the release.

## Why 0.5.2

0.5.1 was published without `localreel-<version>-x64-setup.exe`. The release job
copies every artifact into one directory before uploading, and that step only
knew about `.zip`, `.msi`, `.tar.gz`, `.deb`, `.AppImage`, `.dmg` and `.spk`, so
the setup never reached the upload glob: the release went out without it while
`docs/install.md` recommended it. The collector includes `*-setup.exe` now.

The Linux job in 0.5.1 also failed once in the AppImage step because the script
downloaded `appimagetool` with a silent `curl`; it now retries, keeps the error
visible and refuses a partial download.

## Changes

### Plugins are supervised

- The server owns the lifecycle: `starting`, `running`, `unhealthy`, `failed`,
  `disabled`, `stopped`. The admin page shows the state, the reason and the
  restart count instead of a boolean.
- One supervisor thread converges observed state towards the requested state, so
  restarts cannot race a newer intent.
- A process that dies is noticed within 250 ms and restarted with 1/2/4/8/16 s
  backoff, five attempts. Corrupt packages, bad manifests and wrong API versions
  are permanent and are not retried; handshake timeouts are.
- Health checks every 10 s; three failures mark the plugin unhealthy, six
  replace the process, three such restarts stop it.
- Stopping drains: new calls are refused, in-flight requests finish within
  `stop_timeout_secs` (default 5 s), then the process is terminated.
- Children do not outlive the server: job objects on Windows, process groups on
  Unix, and SIGTERM now takes the same drain path as Ctrl+C.

### Control plane and observability

- `POST /api/v1/plugins/{id}/restart|enable|disable` and `GET .../logs`.
- `?persist=true` rewrites only the matching `enabled` in `localreel.toml`,
  keeping comments and formatting.
- The sidecar's stderr stays in a 64 KiB ring buffer; `plugin_audit` is pruned
  daily keeping 30 days; `doctor` prints the plugin list and failure policy.

### Windows: per-user setup

- `localreel-<version>-x64-setup.exe` installs for the current user only, picks
  its language from Windows (Chinese and English), and never touches the library
  in `%LOCALAPPDATA%\LocalReel`.
- `/lang=`, `/S`, `/D=<folder>`, `/uninstall` and `/removedata` for unattended
  use.
- The MSI remains for machines where several accounts share one installation.

## Upgrading

- From 0.5.0 MSI: uninstall it once, then run the setup.
- From 0.5.1: the application is unchanged; 0.5.2 exists so the Windows setup is
  attached.
